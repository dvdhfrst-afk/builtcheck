# Accessibility

Accessibility rules read the built markup the way assistive technology meets it: a screen reader, a keyboard, voice control. They follow WAI-ARIA 1.2 (the Web Accessibility Initiative's Accessible Rich Internet Applications specification) and the parts of WCAG 2.2 (the Web Content Accessibility Guidelines) that a static file can show. They cannot replace testing with a screen reader, and they do not check color contrast.

| Rule | Default | Reports |
|---|---|---|
| `a11y/image-alt` | error | An `img` with no `alt` attribute, or an image button (`input type="image"`) or linked image map `area` with no alt text. A decorative image needs `alt=""`, and `role="presentation"` counts as saying so. |
| `a11y/placeholder-alt` | warning | Alt text that is a file name (`hero-banner.jpg`, `IMG_2041`, or the image's own file name) or a placeholder word such as "image" or "photo". |
| `a11y/control-name` | error | A form field (`input`, `select`, `textarea`, or an element with a role such as `checkbox` or `textbox`) with no accessible name. |
| `a11y/label-for` | error | A `label for` names an id that is not on the page, or an element a label cannot label, such as a `div`. |
| `a11y/link-name` | error | A link with no accessible name, such as an icon-only link. |
| `a11y/button-name` | error | A button with no accessible name, such as an icon-only button, or an `input type="button"` with no `value`. |
| `a11y/aria-reference` | error | `aria-labelledby`, `aria-describedby`, `aria-controls`, `aria-owns` or another reference attribute names an id that is not on the page. |
| `a11y/duplicate-id` | error | An id that a `label for` or an ARIA reference depends on is on more than one element, so only the first counts. |
| `a11y/aria-role` | error | A `role` attribute holds no WAI-ARIA role, only misspelled or abstract ones. |
| `a11y/aria-attribute` | error | An `aria-*` attribute that WAI-ARIA does not define, usually a misspelling such as `aria-labeledby`. |
| `a11y/hidden-focusable` | error | Something inside `aria-hidden="true"` can still take keyboard focus, so keyboard users land on what screen readers do not announce. |
| `a11y/positive-tabindex` | warning | A `tabindex` above 0, which pulls an element out of reading order for keyboard users. |
| `a11y/heading-order` | warning | A heading skips a level, such as an `h4` straight after an `h2`. |
| `a11y/frame-title` | error | An `iframe` with no title. |
| `a11y/video-captions` | warning | A `video` with no captions track. |
| `a11y/autoplay-audio` | warning | `audio` or `video` that plays sound by itself, with `autoplay` and without `muted`. |
| `a11y/html-lang` | error | The `html` element has no `lang` attribute. Only presence is checked here. |
| `a11y/main-landmark` | warning | More than one visible `main` landmark, or a page with navigation but no `main`, heading or skip link after it. |
| `a11y/table-headers` | warning | A data table with no header cells. |
| `a11y/th-scope` | error | A `th` whose `scope` is not `row`, `col`, `rowgroup` or `colgroup`. |
| `a11y/autocomplete` | warning | An `autocomplete` value that is not a valid token list, such as `autocomplete="nope"` or `"email work"`. |
| `a11y/meta-refresh` | error | A `meta http-equiv="refresh"` that moves people to another page, or reloads this one, after a delay. |

Options:

- `a11y/placeholder-alt`: `placeholders` lists the alt texts that describe nothing, compared whole, ignoring case and a trailing period or colon (default "image", "img", "photo", "picture", "graphic", "icon", "placeholder", "untitled", "alt", "alt text", "image alt", "alt tag", "spacer", "blank", "insert alt text", "image description"). Leftover text such as "TODO" in alt text is `copy/placeholder-text`'s to report.
- `a11y/control-name`: `allowPlaceholder` (default `true`) counts a `placeholder` as a name, as browsers do. Set it to `false` to report fields whose only label is a placeholder, which disappears as soon as someone types.
- `a11y/aria-reference`: `attributes` lists the reference attributes to check (default all eight: `aria-activedescendant`, `aria-controls`, `aria-describedby`, `aria-details`, `aria-errormessage`, `aria-flowto`, `aria-labelledby`, `aria-owns`). Leave out `aria-controls` if scripts create the elements your toggles control.
- `a11y/aria-role`: `allowRoles` lists extra role values to accept.
- `a11y/aria-attribute`: `allowAttributes` lists extra `aria-*` attribute names to accept.
- `a11y/video-captions`: `trackKinds` lists the `track` kinds that count as captions (default `captions` and `subtitles`; a `track` with no `kind` is subtitles). `ignoreMuted` (default `true`) skips a video marked `muted`, such as a background loop with no sound. A video with no source in the markup is not checked, since the script that loads it usually loads its captions too. Turn the rule off with `"a11y/video-captions": "off"` if your videos have no speech.
- `a11y/autoplay-audio`: `allowWithControls` (default `true`) accepts autoplaying media that shows its `controls`, since people can pause it.
- `a11y/autocomplete`: `allowValues` lists whole values to accept, compared ignoring case, such as a value a site uses on purpose to stop browsers filling a field. Only fields that take a field name are checked: text-like inputs, `select` and `textarea`, and `on` or `off` on a `form`.
- `a11y/main-landmark`: `requireMain` (default `false`), when true, reports every page with text and no `main` element, whatever else it has.
- `a11y/meta-refresh`: `checkReload` (default `true`) also reports a page that reloads itself on a timer. A delay of 0 is an ordinary redirect and is not reported, and neither is a delay over 20 hours, which WCAG treats as no time limit.

Every rule except `a11y/html-lang`, `a11y/main-landmark` and `a11y/meta-refresh` takes `ignoreSelectors` (default none): CSS selectors, such as `#chat-widget` or `.third-party-embed`, for elements that are not checked, along with everything inside them. A selector this tool cannot read stops the run with an error rather than matching everything.

## What counts as hidden

Rules about what is announced (alt text, names, headings, landmarks, tables, frames and captions) skip content that assistive technology never meets as the page is built: anything inside `aria-hidden="true"`, the `hidden` attribute, `inert`, `template` or `noscript`, an inline style or a stylesheet that always hides it, at every screen width. Content hidden only at some widths is checked, since it shows at the others. Visually hidden text, such as a `sr-only` class, is announced and counts as a name.

Rules about whether the markup is valid (`label-for`, `aria-reference`, `duplicate-id`, `aria-role`, `aria-attribute`, `positive-tabindex`, `th-scope`, `autocomplete`) check hidden content too, since a script may show it and the markup is just as wrong then. Nothing inside a `template` is checked, and an id that only a template holds counts as present, since a script may add it.

`a11y/autoplay-audio` checks hidden players as well: hiding a player does not silence it.

## Accessible names

A name comes from, in order: `aria-labelledby`, `aria-label`, the element's own alternative, and `title` as a last resort. The element's own alternative is `alt` for images, a `label` element (by `for`, or one wrapped around the field) for form fields, `value` for input buttons, a `title` child for an SVG, and the text inside for links, buttons, headings and other roles named from their content. Text inside counts the `alt` of images and the `aria-label` of elements within it, and leaves out what is hidden. An element that `aria-labelledby` points at counts even when it is hidden, which is a valid way to keep a label off screen.

Text that only a stylesheet adds with `content` is not read, so a link named only by CSS generated text is reported. Icon fonts, the usual case, add no words anyway.

A link or button whose only content is an image with no `alt` is reported once, by `a11y/image-alt`, while that rule is on.

## Headings, landmarks and tables

`a11y/heading-order` follows visible headings in page order, including `role="heading"` with `aria-level`, and an `aria-level` on an `h1` to `h6`. Empty headings are skipped. The first heading may be any level.

`a11y/main-landmark` reports a missing `main` only when a page has a `nav` or a top-level `header` (or `role="navigation"` or `role="banner"`), text after it, and no heading or in-page skip link after it. A heading or a skip link already lets people past the navigation (WCAG 2.4.1, Bypass Blocks). Redirect pages, pages with no text, such as the shell of a single page application, and files with no `html`, `head` or `body` are not checked. A `main` hidden at some screen widths does not count toward "more than one".

`a11y/table-headers` treats a table as a data table when it has at least two rows and two columns of cells, holds no other table, and has no `role` other than `table`. Mark a table used only for layout with `role="presentation"`.
